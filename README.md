# Juan Xavier Cabello

## Full-stack web developer · Educador · Constructor de productos digitales

![Marca visual del fénix púrpura](assets/github-phoenix-banner.png)

Construyo productos web que convierten ideas complejas en experiencias claras y útiles. Mi trabajo combina **TypeScript, React, Next.js, Node.js, bases de datos, WordPress, automatización e inteligencia artificial** con una perspectiva formada por la educación y las matemáticas.

Me interesa crear tecnología con propósito: herramientas que ayuden a aprender, trabajar mejor y tomar decisiones con más claridad. El fénix representa mi forma de entender el desarrollo: aprender, reconstruir, mejorar y convertir cada etapa en una versión más fuerte.

## Proyectos destacados

### [NubeParaPymes](https://nubeparapymes.online)

Proyecto editorial y de producto para pequeñas empresas. Incluye contenidos, comparativas de software y herramientas gratuitas que funcionan desde el navegador para resolver tareas de ventas, facturación, SEO, marketing, operaciones y documentos comerciales.

### [Mundos Simulados](https://mundossimulados.online)

Proyecto editorial de escenarios científicos, tecnológicos, económicos y naturales. Cada artículo parte de una variable modificada, sigue sus consecuencias paso a paso y distingue entre evidencia, modelo y especulación.

### [Math Video Generator](https://github.com/juanxaviercasa/math-video-generator)

Sistema full-stack para generar videos educativos de matemáticas con React, Express, TypeScript, Manim, LaTeX, FFmpeg, narración e integraciones de IA.

### [Potencia Colab](https://github.com/juanxaviercasa/potencia-colab)

Aplicación con autenticación, almacenamiento, importación de datos, progreso personal, seguridad, base de datos y pruebas automatizadas.

### [Sistema Creativo](https://github.com/juanxaviercasa/sistema-creativo)

Producto con automatizaciones, integraciones de IA, documentación de producto, accesibilidad, casos de demostración y pruebas.

### [Zenit — Plataforma Educativa](https://github.com/juanxaviercasa/zenit-plataforma-educativa)

Plataforma educativa con Next.js, MDX, contenido interactivo, expresiones matemáticas y materiales orientados al aprendizaje.

### [NubeParaPymes — Herramientas para pequeñas empresas](https://github.com/juanxaviercasa/nube-para-pymes)

Colección de herramientas web para problemas comerciales y operativos de pequeñas empresas.

## Tecnologías

**Frontend:** TypeScript, JavaScript, React, Next.js, Vite, HTML, CSS, Tailwind CSS y MDX.  
**Backend:** Node.js, Express, APIs REST, tRPC y validación con Zod.  
**Datos y plataforma:** MySQL, Drizzle ORM, Prisma, Redis, S3, autenticación y almacenamiento.  
**Calidad:** ESLint, Prettier, TypeScript checks, Vitest, documentación técnica y workflows de CI.  
**Contenido y CMS:** WordPress, estructura editorial, SEO básico y publicación web.

## Cómo trabajo

Parto de un problema real, diseño el flujo principal, construyo una interfaz comprensible, separo responsabilidades entre frontend y backend y documento lo necesario para que el resultado pueda mantenerse. Mi experiencia como educador me ayuda a explicar sistemas complejos con orden, lenguaje claro y atención a la experiencia de quien los utiliza.

## Filosofía personal

Creo en el aprendizaje continuo, la disciplina y la construcción intencional. Mi interés por el crecimiento personal y la visión simbólica del fénix forman parte de mi identidad; en mi trabajo se expresan como curiosidad, perseverancia y voluntad de convertir una idea en una solución verificable.
